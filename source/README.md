这里是**小克（Chloe）一切素材的源头**。仓库里 `app/assets/chloe/` 下的立绘、表情、Q 版小人，都是从这三张图裁切 + 抠图生成的。

**这三张图必须保留**——删了就没法重新生成素材，也没法在换脸/加表情时回溯。

## 注意事项

- **图里印的文字不会进 App**。`01` 里写着"姓名 小柔"以及"虚拟陪伴减肥姬"等说明文字，那只是设定稿；App 里的名字是 **小克 / Chloe**，由 `app/js/characters/chloe.js` 决定。
- **背景不一样**，抠图方式也不同：`02` 是白底，`03` 是深色渐变底（深色头发和背景很接近，简单阈值抠不干净）。所以统一用 `rembg` 的 `isnet-anime` 模型处理，见 `tools/build_assets.py`。
- **装饰文字和爱心会被自动过滤**：脚本里用"只保留最大连通块"的办法去掉那些和人物不相连的文字、爱心、星星。
- 表情卡片底部的粉色文字角标（"开心""害羞"等）在裁切时用颜色定位避开了，没有混进素材里。

## 怎么重新生成

```powershell
python -m pip install rembg onnxruntime   # 首次会下载约 176 MB 的抠图模型
python tools/build_assets.py              # 生成 app/assets/chloe/ 全套素材
```

生成结果可以打开 `tools/preview/sheet_assets.png` 对照检查。
